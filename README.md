# LLM Wiki 101

> Build persistent LLM-maintained knowledge bases — Karpathy's "LLM Wiki" pattern, distilled

A bilingual (English + Thai) self-paced engineering training. Two tracks:
1. **Foundations** — for researchers and PKM enthusiasts
2. **Engineering patterns** — for building production knowledge systems

🌐 **Live:** https://supachai-j.github.io/llm-wiki-101/ _(after deploy)_

## What's inside

- `index.html` — landing page
- `course-en.html` / `course-th.html` — self-paced courses (12 modules)
- `slides/` — reveal.js decks
- `wiki/` — cited knowledge pages
- `raw/` — captured primary sources (Karpathy gist + adjacent academic)
